# Liz Inspired Technologies

Live Site: [https://GloryEli.github.io/liz-inspired-tech/](https://GloryEli.github.io/liz-inspired-tech/)

## Overview

Liz Inspired Technologies is an enterprise AI engineering and consultancy platform dedicated to architecting smart, scalable machine learning systems, high-throughput backend APIs, and data-driven solutions for real-world business applications.

## Core Services & Capabilities

- **Custom AI & Machine Learning:** Predictive modeling, classification algorithms, and tailored NLP pipelines.
- **Backend API Architecture:** Production-ready Python (FastAPI/Django) services built for real-time model inference and secure data routing.
- **Data Analytics & Operations:** Transforming complex metrics into clean actionable dashboards, automated pipelines, and operational decision support tools.
- **Live System Deployments:** Engineering and maintaining production systems (e.g., Academic Bloom).

## Technical Architecture

- **Frontend Presentation Layer:** HTML5, Tailwind CSS, JavaScript (ES6+), FontAwesome
- **Planned Backend / AI Integration:** Python 3.x, FastAPI, PyTorch, Scikit-Learn, Uvicorn
- **Deployment & Hosting Strategy:** GitHub Pages (Static Presentation Site), Render / Hugging Face Spaces (Backend Inference Microservices)

## Local Setup & Inspection

```bash
# Clone the repository
git clone https://github.com/GloryEli/liz-inspired-tech.git

# Navigate to the project directory
cd liz-inspired-tech

# Launch local preview server
python -m http.server 8000
```

Open http://localhost:8000 in your web browser to view the site locally.
